# Surface: index.html (whole game page)

Scope: the single page of Spyfall Anime: home (Créer, Animés, Rejoindre) and the game screen. Visitor mode: Operate. Build path: code-led (no image generation).

Audience and job: friends on a Discord call, each in their own Chrome tab on PC, no screen sharing. Host sets up in under a minute; players join with code + number, read their card, run the three phases, enter the majority vote, see the verdict, move on together.

Constraints: French copy, static HTML, card logic and the 92-card list are product truth and stay unchanged. No anime artwork.

## Direction contract

THESIS: every round is a pull from a capsule machine: your card is the one capsule you got, opened in private. No list of possible answers is shown (user decision: it made the spy's guess too easy). Refuses the category default: a grey lobby with a flat text card.

OWN-WORLD: graphite machine-body ground; capsule plastics as the category system: clear tinted top, coloured bottom (Lieu sky blue, Objet yellow, Groupe tomato red), the spy gets a fully clear capsule; the white paper ticket inside is the reading surface; pop rounded display face with a rounded workhorse body; round coin-dial primary buttons only for "open" and "next pull".

STORY: the visitor understands their role in one glance, trusts that everyone got the same pull, and always knows the one next action of the phase.

FIRST VIEWPORT: top bar with name and the player, round, code status; left work area: closed silver capsule at about 260px (170px at 520px and below) labelled "Tourne pour ouvrir", right work area: the phase stepper and the phase panel holding the primary action, then round navigation.

FORM: candidate 6 of 7 (gachapon machine), seed:dc874e6ed7b6a682. Signature move: the capsule twist-open reveal, halves rotating apart.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
